# Planned Fabric source tables

The Fabric implementation will bind entity types to Lakehouse tables. The first demo can use one table per major ACORD entity and foreign-key columns for relationships.

Planned Phase 0 tables:

- `claims_fact`
- `loss_notification`
- `loss_occurrence`
- `financial_services_agreement`
- `party`
- `claim_declarer`
- `vehicle`
- `place`
- `peril`

No production or personal data is included in this starter repository.
